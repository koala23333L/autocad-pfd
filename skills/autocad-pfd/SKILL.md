# AutoCAD 化工 PFD 绘图

通过 `autocad-pfd` MCP 服务器（COM 自动化）在本机 AutoCAD 中绘制 PFD。模型空间 1 单位 = 1 mm，
A0 图纸即 1189×841。图例画法逐条对照 HG/T 20519 常用图例（设备/阀门/仪表/管道符号，
符号定义内置于 `symbols.py`，成图总表 `references/generated/symbols_all.png`）。
`references/` 支持自备参考资料（设备图例扫描件/制图手册裁剪图等，放入后
`list_references` 工具动态列清单），绘制不熟悉的设备前**先 Read 对应参考图**核对画法。

## 前置检查与故障处理

1. 先调用 `autocad_status`。若 `running=false`，调用 `new_drawing` 会自动启动 AutoCAD
   （冷启动约 1~3 分钟）。
2. **若工具报"被呼叫方拒绝接收调用"**：AutoCAD 有模态框挡住消息循环——最常见是
   "登录 - Autodesk" 提醒框（教育版可离线用，直接叉掉即可）。运行
   `python <plugin>/server/dismiss_login.py` 自动关闭（含跨进程登录窗，只关窗不输凭据）；
   仍卡住时 `taskkill /f /im acad.exe` 后重跑 `wait_ready.py`。
3. 每次成图前建议 `new_drawing` 新建文档，避免把图混进用户正在编辑的文件。

## 两种工作方式

**A. 一次性成图（推荐）**：整理工艺数据后用 `draw_pfd(spec)` 画整图。spec 要点：
- `frame` + `title`（标题栏：设计/校核/审核/批准不能同一人；dates 列表按行填日期）。
- `equipment[]`：kind/tag/name/x/y/size/rotation/options。**options.nozzles** 只画用到的接管
  （如塔 ["top","top_L","bottom","side_L_up","side_R_dn"]），避免悬空短桩；**label_xy** 手动定位位号。
  端口名：泵 suction(左)/discharge(右上切线口)；换热器 tube_in(左)/tube_out(右)/shell_in(上)/shell_out(下)；
  塔 top/top_L/top_R/bottom/side_L(_up/_dn)/side_R(_up/_dn)；再沸器 process_in(釜底)/vapor_out(汽相顶)/heating_in/out(通道上下)；
  混合器 TL/T/TR(顶边进料)/B(底角出料)；分层器 feed(顶)/organic(右轻相)/aqueous(底重相)。
- `pipes[]`：from/to 用 [tag, port] 或原始坐标 [x,y]（进出图纸线），自动正交走线并**避开设备包围盒**；
  复杂走向用 via 途经点；kind=main 粗线/aux 中线；stream_no 画流股号圆圈（白底遮罩自动压断管线）；
  label 画管道标注（横向在管上方、竖向在管左侧并自动避开流股号圆圈）。
- `connectors[]`：管道进/出图纸符号 {text 管线号, x, y, flow_dir ±1, label 来自XX/至XX}。
- `equipment_table`：**设备位号-名称一览（图例式，无框线）**——用户明确要求：不许画大网格表！
  每项 = 位号(上)+短横线+名称(下)（与图中设备标注同款），自左向右横排、到装订边自动换行成几排。
  {x, y(首行位号基线), width, per_row(每项数，如 9)}；条目自动取 equipment 的 tag+name。
  放底部时先压缩版面腾出 y<105 的空带（底部产品/污水线抬到 y≥112）。
- `instruments[]`：letters=检测参数+功能代号（如 TIC），number=位号，connect_to 接工艺点。
  **引出线要短且不穿管线**：气泡放在离管线 30~60mm 处，垂直/水平连接。
- `table`：物料表（行序固定：物流代号/温度/压力/汽相分率/摩尔流率/总质量流率/组分）。
- `save_as`/`export_png`/`export_pdf` 直接落盘。

**B. 逐步绘制**：`new_drawing` → `draw_frame` → `add_equipment`（记住 ports）→ `add_pipe` →
`add_valve`/`add_instrument`/`add_stream_connector`/`add_heat_load` → `draw_material_table` →
`save_drawing`+`export_drawing`。

## 规范要点（可用 get_standards 查完整表）

- 设备位号 = 分类代号+主项号+顺序号(+尾号)，如 P101、T101A。位号在上、粗实线、名称在下（自动），
  **默认居中于设备正上方**；若该处有管线穿过（如塔顶双管），用 label_xy 移到设备侧上方空白处。
- 管道标注 = 物料代号+主项+分段号-管径+等级+隔热，如 `PG 08 01-50 B2A H`。
- 线宽：主物料 1.0mm 粗、辅助/公用 0.5mm 中、其余 0.25mm 细（已按图层内置）。
  **全图单色（ACI 7）**——标准图例明确打印版不能靠颜色区分流股。
- 物料表流股号与图中圆圈一致，两位小数；物料表放图左下。
- 仪表圆圈：上半字母、下半数字；mount=field 单圆/central 圆内横线/local 圆内十字/
  dcs 圆外方框/inpipe 横线穿出（附表2-4）。
- 布局红线：任何设备/管线/文字**不得压标题栏**（A0 标题栏占右下角约 340×120mm，
  即 x>829 且 y<140 的区域）；设备间留白 ≥20mm；A0 细身设备可容 15~20 台，
  流程自左向右按工段展开（如 反应→分离→精制，按具体工艺定），底部留设备一览带。
- 中文注释字号：设备位号/名称 5mm、流股与工质标注 ≥3.5mm（预检 errors 拦截 <3.5），
  打印必须可读——用户明确反馈过"中文字号还得大点"。
- 设备代号对照（表8-2）：泵 P、反应器 R、换热器 E、压缩机/鼓风机 C、工业炉 F、
  容器 V、塔 T、火炬烟囱 S、其他机械 M、其他设备 X；位号=代号+主项号+顺序号。
- 反应条件注记写在反应器旁（如"320℃ 丙烯→丙烯醛"），换热负荷可标 Q=XXkW。

## 成图后自检（必做，不可跳过）

预检已在 draw_pfd 内自动执行（errors 会直接拒绝成图），但**目视复核不可省**：
`python <plugin>/server/inspect_png.py <导出的png> <spec路径> [输出目录]`
——自动检测图框完成 mm→px 标定，逐台设备裁特写 qa_<位号>.png + 底部一览 qa_bottom.png +
标题栏 qa_title.png，**逐张 Read 确认**：
1. 中文正常（???? = 文字样式被改坏，重调 new_drawing）；
2. 位号/标注/圆圈不压管线与设备（调 label_xy / via）；
3. 无悬空接管短桩（加 nozzles 过滤）；
4. 设备不侵入标题栏区；
5. 图框、标题栏、物料表完整。
发现重叠就改坐标重跑，直到干净为止。

## 工作流红线（用户流程要求，违者打回）

1. **先备份再大改**：任何结构性返工（改符号/重排布局）前，把 out 下 dwg/png/pdf 与 spec
   复制到带版本号的备份目录（如 `out\backup_v1_日期\`），用户要求"你先备份原版，然后去做"。
2. **画法必须查证**：每个设备的 PFD 画法动手前要**对照标准图例原件 + 上网搜索**确认
   （用户原话"要你上网挨个搜索他们在pfd图中怎么画"），禁止凭印象自创；查证结论写进
   画法修正记录。
3. **一致性**：同类设备必须同画法——修正一处（如封头形式、管板线）时**全类设备同步生效**，
   不允许"顾头不顾腚"改一台漏一批。
4. **从符号层修，不打补丁**：用户指出问题时先定位根因（符号函数/端口坐标/布线规则），
   修通用层并同步更新预检规则与 SKILL.md，而不是对当前图打坐标补丁。
5. **模拟图只作工艺参考**：工艺模拟软件导出的流程图，其设备连接与物流是对的，但其**排布、走线、图块样式
   一律不照抄**——PFD 按 HG/T 20519 与标准图例重新布局。
6. **交付动作**：改完 → AutoCAD 打开最终 DWG 并置前（ZOOM E）→ 向用户说明改了什么、
   为什么、验证结果。
7. **模型工艺合理性由用户口径兜底**：用户指出工艺逻辑问题（如"不可能只进一股混合气"）时
   按用户口径改流程，不与用户争辩规范出处。

## 常见工段与设备选型对照（普适——本 MCP 不限于某一产品）

设备种类（kind）：pump/compressor/blower/vacuum_pump/heat_exchanger/air_cooler/column
/vessel/separator/reboiler/mixer/fixed_bed_reactor/reactor/decanter/cyclone/ejector
/flare_stack/filter_press/centrifuge/storage_tank/fired_heater。按工段常见组合：

- **精馏/脱水/溶剂回收**：column(tray)+reboiler(釜式)+heat_exchanger(塔顶冷凝器)
  +vessel(回流罐)+pump(回流/采出)+decanter(共沸分层)+storage_tank(产品罐)。
  **塔**：封头高 0.35 倍直径（必须明显鼓出，不许近 Flat）；塔板满跨均匀分布
  （示意 ≤12 条、贴近上下封头，禁止中密两端空）；**釜式再沸器内件=圆角矩形管束
  +通道内管板横线**（标准图例釜式格画法，不是稀疏 U 形管）。
- **吸收/洗涤/急冷**：column(packing)+separator(急冷分液)+mixer(药剂配制)
  +heat_exchanger(循环冷却器)+pump(循环泵)，吸收剂标注 来源/循环。
- **反应工段**：mixer(多股原料各自管线进混合器)+fixed_bed_reactor(气固催化)
  或 reactor(搅拌釜)+heat_exchanger(段间/最终冷却)+separator(产物分离)。
- **除尘/气固分离**：blower(输送)+heat_exchanger(加热)+cyclone(旋风)+flare_stack(尾气排放)。
- **真空系统**：ejector(蒸汽喷射)+vacuum_pump(水环)+heat_exchanger(冷凝)+separator(分液罐)。
- **蒸发/干燥**：reboiler(作蒸发器/釜)+column(packing)+cyclone(气固分离)+blower。
- **固液分离**：filter_press(板框)+centrifuge(离心)+pump+storage_tank(滤液罐)。
- **冷/热公用工程**：heat_exchanger(水冷, CWS/CWR)、air_cooler(空冷)、fired_heater(加热炉)。

遇到标准图例里没有的设备：先上网查证标准画法 → 在 symbols.py 新增 kind（符号函数+extents
+PORT_DIR+注册）→ layout_check._body_rect 补本体矩形 → 本文件记录画法。

## 一次成图 checklist（历轮用户红线汇总——违反任何一条都会被预检拦下或被打回）

**流程（务必按序）：**
1. 写 spec（单一事实源，独立 py 模块，绘图与预检共用；严禁绘图脚本内嵌另一份坐标）。
   **设备坐标可省略**——server 自动按流程顺序排布（自左向右流式、行满换行）；
   `auto_stream_no:true` 自动给未编号主物料线补流股号；无 via 的管线自动走线且**避让已画管线**。
2. 先调 `check_pfd_layout(spec)`（或直接 draw_pfd——它成图前自动跑同一套预检，
   **有硬伤直接拒绝成图并返回完整违规清单**，按清单改 spec 重试，errors 清零才出图）。
3. 成图 → `python server/inspect_png.py 导出的png spec路径` → 逐台设备特写目视复核。
4. 设备一览放底部：先压缩流程区腾出 y<105 空带（底部产品/污水线抬到 y≥112）。
5. **版面均衡**：成图后看整图，若某一角设备堆叠、另一大片空白=布局不合格（用户指认
   "右上角堵死、其他地方空落落"）。根因常是某设备的冷凝器/回流罐放到了远离本塔的位置——
   把它移回本塔附近或填入空带；反应器改侧口进料（side_L）可腾空塔顶/设备上方的走线走廊。
   移动设备后必须重排其相连管线（删旧 via 手工给正交新路径，自动走线在密集区会出斜线）。

**设备符号（图例表8-2 为唯一基准，禁止自创）：**
- 混合器=倒三角（进料段需左→右读图时 rotation:90 → 右指三角，左缘进料、右顶点出料）；
  **多股原料必须各自单独管线进混合器**（用户工艺口径），不许预先混合成一股进料。
- 闪蒸罐/分离器=顶出气+底出液+侧线进料（带进口挡板+顶部除沫器虚线），侧出气=工艺逻辑错误。
- 固定管板换热器=胶囊壳+**两端各一条竖直管板线封口**+两管板间细管束线；
  加热器/冷却器/冷凝器同符号（E 类按结构分型式、不按用途分）。
- 塔底再沸器=釜式（通道封头+汽相空间釜体+U 形管束），不是普通管壳换热器。
- 塔/容器/分离器/分层器/固定床反应器=细身+浅椭圆封头（塔宽 0.2H、反应器 0.3H、封头高 0.25W），
  严禁大半圆头"椭圆罐"；卧式换热器/再沸器才用胶囊头。
- 固定床反应器接管：top 进/bottom 出；**侧口只许在床层（矩形+X）上方 0.33s
  （side_L/side_R）或下方 0.33s（side_L_low/side_R_low）的直壁段**，
  严禁开在床层矩形正中（X 交叉点=捅穿床层）。
- 离心泵：吸入线画到圆心、排出线从圆右缘切点竖直向上带箭头、开口梯形支座。

**标注与可读性：**
- 每台设备必须有 位号+名称 注释，且**位号紧贴设备**，不许甩到远处（否则=无标识罐体）。
- 进料线标 来源（来自XX）、出料线标 去向（去XX）；物料表数据未知就不画。
- 流股号=空心细线圆**骑在管线上**、管线断口留缺口（r+1.5），数字居中；
  **严禁白色实心遮罩**（深色背景下数字会消失成一片实心白点）。

**阀门与仪表（按工艺实际布点，不许敷衍）：**
- **阀门数量按工段实际**——整图只画两三个阀门=不合格（用户指认"个人都知道不可能这么少"）：
  每个控制回路 1 个**调节阀 kind=control（气动薄膜头）**，与控制器仪表位号成对
  （FIC↔FV 流量、TIC↔TV 温度、LIC↔LV 液位、PIC↔PV 压力）；塔底液位→釜液采出线、
  回流罐液位→塔顶采出线、进料流量、吸收剂/洗涤水、再沸器蒸汽量各一条调节阀回路；
  **界区隔离阀 kind=gate** 画在 进料/产品/尾气/污水 出入装置处；减压/放热需求处用
  kind=reducing。批量成图在管道 valves 里用 {"kind":.., "at_xy":[x,y]} 按坐标放阀
  （**自动吸附到管线**，避免手算比例落偏）。
- **仪表圆圈必须落在被测管线上或设备筒体直壁段**（液位表 LIC 接塔/罐直壁，
  温度/压力/流量接对应工艺管线），**严禁悬空引线**（预检 errors 强制拦截）；
  控制器圆圈尽量靠近其调节阀所在管线，避免斜引线。
- 阀门/仪表避让：不压流股号圆圈、不压文字、不落设备本体（流股号在最长段中点，
  同线放阀时错开；可在 spec 加 via 挪开流股号）。

**几何红线（预检 errors 一票否决）：**
- 管线全正交，**严禁斜线**；接侧口/旋转设备口必须 via 沿端口轴线引入。
- 接管短桩从封头曲线交点或壁面起笔，**设备内部不许留线头**。
- 管线不穿设备本体、不出图框、不入标题栏；不闯底部设备一览区；无悬空接管、无假 T；
  **仪表引线不悬空**。
- 阀门不落进设备内部（调 valves.at / at_xy）。

**底部设备一览（图例式，不是网格表）：**
- 每项=位号(上)+短横线+名称(下)，与图中设备标注同款；按行均分布满整幅宽度，
  **项与项之间留空格**，到装订边自动换行成几排。spec 键 equipment_table={x,y,width,per_row}。

## 画法修正记录（用户逐轮指认、已定稿的红线，改符号前必读）

1. **离心泵（表8-2）**：圆；吸入水平线从左侧**画到圆心**；排出线**从圆右缘切点 (r,0) 起笔**
   竖直向上、顶端箭头——**绝不能从圆下方起笔穿过右侧端点**，要与圆相切；
   支座是**开口梯形**（两斜腿从圆下缘外撇+底部横线，顶边由圆弧收口），**不是封闭三角形**。
2. **固定管板换热器（表8-2）**：卧式胶囊壳+**两端各一条竖直管板线**（固定管板=管束两端都固定
   在管板上，右端**必须封口**，绝不能只画左端）+**两管板之间 4 条水平细管束线**（线宽 18，
   不抢壳体线宽）；管程接管在左右两端水平、壳程接管上(偏左)/下(偏右)。
   **加热器/冷却器/冷凝器/换热器符号相同**（同属 E 类管壳式，HG/T 20519 按结构分型式、
   按用途不分子符号），用途差异靠流股与公用工程标注体现。
3. **闪蒸罐/分离器（kind=`separator`）**：立式浅封头壳，**气相口必须在顶部、液相口在底部、进料从侧线**
   （侧线进料带进口挡板，顶部加丝网除沫器虚线）。**绝不能把气相口画在侧中部、顶部封死**——
   闪蒸罐气液分离靠顶出气、底出液，侧出气是工艺逻辑错误（用户两次指认）。
   端口：inlet(侧)/top(顶气)/bottom(底液)/vapor_out(侧气，仅特殊场合用)。
4. **塔底再沸器**：**不是普通管壳换热器**！用标准图例换热器行"釜式"格（kind=`reboiler`）：
   左小通道封头+右带汽相空间釜体（顶线斜升、右端圆弧）+内 U 形管束；
   塔底液从**釜体底**进、气相从**汽相空间顶**出返塔、**加热介质必须接通道上下口**
   （heating_in 蒸汽进、heating_out 凝液出，配 公用工程辅线+标注）——
   **再沸器没有热源管线=工艺逻辑错误**（用户指认）。四路缺一不可。
5. **混合器（kind=`mixer`）**：**倒三角形**（Aspen MIXER 同形）——默认顶边进料(TL/T/TR)、底角出料(B)。
   **进料段要左→右读图时给 equipment 加 rotation:90**（逆时针转 90°=右指三角 ▶：
   左缘竖边三口进料、右顶点出料，出料与下游设备侧口同高直连）。
   旋转设备的 extents/rect 必须**随 rotation 旋转**（90° 时交换 dx/dy 并取反），
   否则端口会落进未旋转包围盒内部，管线被判"穿设备"。
   **不是矩形+之字元件的静态混合器**；多股气体必须先各自入混合器再进反应器。
   ⚠ rotation 后端口方向 d1 是斜向，**该设备的连线必须全部给 via 显式正交走线**。
5b. **管线一律正交**：PFD 不允许斜线——server 的 _route 对**侧向端口**（offset 非水平/垂直，
    如塔 side 口 (±66,75)、旋转混合器口）算出的引入方向是斜的，**凡接侧口的管线必须给 via**
    且末段沿端口轴线方向。再沸器 process_in/vapor_out 世界坐标 = (x+xd+0.3L, y∓(c+st))、
    (x+xd+0.1L, y+v+st)（xd=xr−0.3L, xr=L/2−rc），**手算必须按此式，差 2mm 就是斜线**。
    checker 已加"斜线检查"（|dx|>0.5 且 |dy|>0.5 即违规）。
6. **立式设备封头一律浅椭圆**：塔/容器/分离器/分层器/固定床反应器均为**细身+浅椭圆封头**
   （封头高 ≈0.25W，用参数折线逼近，`_shallow_vessel`）；塔身宽约 0.2H、反应器约 0.3H。
   **严禁画成大半圆头"椭圆罐"**（用户明确指认的错误）。卧式换热器/再沸器才用半圆胶囊头。
7. **每个设备必须有位号+名称注释**（tag 在上、粗实线、name 在下，label_xy 定位到设备旁空白处），
   不允许出现无注释的罐体。
7b. **接管短桩不得伸进设备内部**（用户指认"线头"）：立式设备顶/底口的短桩必须从**封头椭圆曲线
   与桩轴线的交点**起笔（y=∓H/2±hh·(1−√(1−(dx/r)²))），正中口曲线点=端口、短桩长度为 0 时不画；
   侧口一律从筒体壁面起笔。绝不允许从"H/2−0.3r"这类内部点起笔穿出封头。
7c. **设备内件两端必须搭在壳体轮廓上**（用户指认"意义不明的线"）：挡板/降液板=全高、
   上下端落在封头曲线上；除沫器=满跨虚线（两壁到壁）；分层器分界线=一端贴壁、
   一端接挡板。**禁止任何内件线端悬空在设备内部**（闪蒸罐挡板曾因两端悬空被指认）。
8. **仪表信号线落点**：必须**恰好落在管线或设备直壁段上**——不得悬空（如落在椭圆封头弧区外的空处）、
   不得穿过去向符号框等其它图形。塔/罐的液位仪表接**筒体直壁段**（立式容器直壁范围 =
   ±(H/2−L/2) 内），温度/压力/流量接对应工艺管线。**此规则已进预检（检查3b），悬空引线=errors 拒绝成图**。
9. **位号框**：不得与设备、管线、图例符号重叠（默认设备正上方，冲突时 label_xy 手动让位）。
10. **流股号圆圈**：细实线小圆圈**骑在管线上**，管线在圆圈两侧**断开留缺口**（半径 r+1.5），圈内写数字。
   **严禁用白色实心遮罩(ACI 255)压断管线**——AutoCAD 深色背景下 ACI 7 数字会变白，白字压白底=数字消失，
   整张图看成一堆"意义不明的实心白点"（用户明确指认）。断线画法在深色/浅色背景下数字都可读。
   圆圈不得骑在接管短桩或设备线上。
11. 一切以 HG/T 20519 与内置标准图例（`symbols.py` /
    `references/generated/symbols_all.png`）为唯一基准；有自备参考资料时先 Read 核对。
    成图后用 `inspect_png.py` 逐格裁剪比对，不允许凭印象自创画法。
12. **固定床反应器侧口必须开在催化剂床层（矩形+X）上/下方的直壁段**：
    side_L/side_R 默认在床层上方 0.33s（气相自上而下穿床层，与标准图例顶进底出同向），
    上行流程用 side_L_low/side_R_low（床层下方）。**绝不能把侧口开在床层矩形正中**——
    那是 X 对角线交叉点，进料管看起来直接捅穿床层（用户指认"反应器怎么画成这个样子"）。
13. **阀门数量按工艺实际、仪表引线禁止悬空**：整图只画两三个阀门=不合格
    （用户对照基准图指认"传感器没接设备浮空、阀门不可能这么少"）——
    每个控制回路一个调节阀（气动薄膜头）+ 对应控制器仪表；界区加隔离阀；
    仪表引线端点必须落在管线或设备直壁段上（检查3b 强制）。

## 严肃重画工作流（多设备图必用，防返工）

1. **单一事实源**：spec 写成独立 py 模块（如 `spec_acrylic.py` 导出 SPEC dict），
   绘图脚本与碰撞检查脚本都 import 同一份，**严禁绘图脚本内嵌另一份坐标**（曾因此改了 spec
   却仍按旧坐标出图，整轮返工）。
2. 先跑**程序化布局检查**（参考 `server/layout_check.py`（MCP 内置）：Mock doc 干跑
   draw_equipment 取真实端口/包围盒，检查 管线穿设备体、文字压线/压设备/互压、悬空接管、
   端点悬空、入标题栏、出图框、假 T 连接），**迭代到 CHECK_CLEAN 才允许成图**。
3. 成图→render_hi→按标定（图框外矩形自动检测，3.678 px/mm）裁剪各区域目视复核。

## 导出机制（已适配 2027）

PDF：Model 布局设 DWG To PDF.pc3 + Extents + Fit + 打印线宽，BACKGROUNDPLOT=0 同步出图。
PNG：先出 PDF 再用 pypdfium2 高清渲染（2027 的布局对象不能设 PNG 设备纸张）。
IAcadPlot 在 2027 已无配置属性，StandardScale 是枚举（0=Fit）不是字符串——代码已处理。
